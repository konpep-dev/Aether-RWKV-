# Aether Model Documentation

This folder contains the **GitHub Pages** documentation for the Aether RWKV model.

## Contents

- `index.html` — Interactive Model Card with complete technical documentation
- `images/` — 9 visualization images showing architecture, training, and performance
- `_config.yml` — Jekyll configuration for GitHub Pages

## Viewing Locally

Open `index.html` in any web browser to view the full model card.

## GitHub Pages

When deployed via GitHub Pages (Settings → Pages → `/docs` folder), this becomes accessible at:

```
https://YOUR_USERNAME.github.io/aether
```

The model card includes:
- Complete architecture breakdown
- Training hyperparameters
- Dataset statistics and composition
- RWKV mechanism explanation
- Performance charts
- Parameter distribution analysis
